실제 소유 경로
- 별도 argocd/gateway Application의 spec.source.kustomize.patches[1].patch가
  /spec/listeners 전체를 replace합니다. target은 gateway-system/main-gateway입니다.
- Gateway 리소스를 직접 patch하거나 공유 repo 파일만 수정하면 Application selfHeal로 되돌아갑니다.
- root는 기존 7개 listener와 addresses 및 다른 override를 보존한 채 같은 Application patch에
  qc-dev-shell-https/qc-dev-modules-https를 append했습니다. 기존 qc.* hostname은 바꾸지 않았습니다.
- qc-prod-app의 valuesObject.global.gateway.shellSectionName/moduleSectionName은 각각
  qc-dev-shell-https/qc-dev-modules-https입니다. 기존 Route 이름/backend/namespace와
  gateway-system/main-gateway 부모 참조는 유지합니다.

별도 인증서
- onprem-qc-dev-tls-certificate.yaml.example은 root가 적용한 별도 Certificate/Secret
  qc-dev-tls(gateway-system)의 예시입니다. 기존 qc-tls Certificate/Secret은 변경하지 않습니다.
- issuer는 기존 letsencrypt-prod ClusterIssuer이며 DNS01로 dev 두 host를 발급했습니다.
  *.quantum-instrument.com은 modules.qc-dev.quantum-instrument.com을 포함하지 않습니다.
- root가 Ready=True를 확인했습니다. 이 예시는 spec만 담으며 상태 증명이나 개인키를 포함하지 않습니다.

Application patch 예시와 재적용 금지
- onprem-dev-gateway-application.jsonpatch.example은 root의 실제 적용 patch를 복사한 이력 예시입니다.
  대상은 Gateway 리소스가 아니라 argocd/gateway Application입니다.
- 당시 resourceVersion 8053940과 기존 patch 원문을 test한 뒤
  /spec/source/kustomize/patches/1/patch를 replace합니다. 이 안의 listener 목록은 7개에서 9개로 늘어납니다.
- 이미 적용한 예시를 재적용하지 않습니다. 향후 변경 시 최신 Application resourceVersion, patch 배열의
  target 및 patch 원문을 다시 조회하고 기존 모든 listener를 보존하는 변경을 root가 검토합니다.
  예시의 resourceVersion만 바꾸어 강제 재사용하지 않습니다. 현장 배열 index도 다시 확인합니다.
